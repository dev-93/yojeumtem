# 요즘템

상품을 고르는 데 도움이 되는 콘텐츠를 만들고, 네이버 쇼핑 커넥트 제휴 링크를 통해 실제 구매와 수익이 발생하는지 검증하는 1인 콘텐츠 사업 실험입니다.

현재 기준 목표는 **첫 제휴 구매 1건**입니다. 누구의 어떤 구매 고민을 해결하고, 그 사람에게 어디에서 도달할 수 있는지 작은 실험으로 확인합니다. 상품, 채널, 콘텐츠 형식은 실험 결과에 따라 선택합니다.

## 사업 기록

최신 목표·우선순위·진행 상태·실험 결과는 Notion을 기준으로 확인합니다. 이 폴더에는 콘텐츠 제작 파일과 작업 지침을 둡니다.

- [프로젝트 홈](https://www.notion.so/3e4eb93112d58130b6d5dfd688af8d6b)
- [실험·결정 기록](https://www.notion.so/413eb93112d581ccb932c9e502ca7740)
- [운영 기준과 수익 가설](https://www.notion.so/413eb93112d58197a8fad508bfac9428)
- [실행 계획과 지표](https://www.notion.so/413eb93112d581b2af09fb6051bb7d19)

Notion의 일부 하위 문서에는 과거 쿠팡·릴스·트렌드 수집 계획이 남아 있습니다. 현재 방향을 판단할 때는 프로젝트 홈과 최근 결정 기록을 먼저 확인합니다. 이번 폴더 정리는 Notion의 페이지나 DB를 변경하지 않았습니다.

## 폴더 구성

```text
README.md       프로젝트 안내와 사업 기록 링크
AGENTS.md       AI와 함께 작업할 때의 기준
assets/         로고 등 공통 제작 자산
experiments/    실험별 문안·이미지·제작 파일
docs/           기술 구현 계획
```

- [Threads 게시글·성과 수집 개발계획서](docs/threads-data-plan.md): 게시글 원문과 성과를 Notion으로 수집하는 구현 제안. 아직 API 연동·DB 생성·배포를 완료한 상태는 아닙니다.
- [Threads 수집 실행 안내](docs/threads-sync-usage.md): TypeScript 수집기 인증 설정·수동 실행·검증 방법. 실제 인증과 정기 배포는 별도로 확인해야 합니다.

실험 파일의 작성·보관 방법은 [experiments/README.md](experiments/README.md)를 따릅니다. 상세 조사와 사업 판단은 Notion에 기록하고 제작 파일에서 해당 기록을 연결합니다.

## 기존 수집 시스템 정리 · 2026-11-10

이 저장소는 Google Trends RSS·네이버 쇼핑인사이트의 키워드를 수집·평가하고, Notion 기록과 Telegram 브리핑으로 연결하던 시스템이었습니다. 마지막 로컬 버전은 자동 상품 발굴 대신 사람이 작성한 상품 JSON을 검사해 최대 3개를 선정하는 방식이었고, 입력은 비어 있었습니다. 이 시스템만으로 구매 의도나 제휴 수익이 검증된 것은 아닙니다.

현재 콘텐츠 실험에 집중하기 위해 수집·점수·브리핑·예약 코드, 테스트, npm 의존성, 배포 설정, 기존 운영 문서를 제거했습니다. 로고와 여행상품 문안은 제작 자산으로 정리했습니다. 정리 당시 실행할 앱이나 npm 명령은 없었습니다. 이후 추가한 Threads 수집기는 위 실행 안내를 참고합니다.

정리 시 Mac의 기존 `com.taenam.coupang-content-briefing` 예약과 plist 파일이 없는 것을 확인했습니다. Railway의 현재 운영 상태는 확인하지 않았으며, 로컬 파일 제거는 외부 배포나 예약을 중지하는 작업이 아닙니다. 기존 Notion 기록, 로컬 `.env`와 `.runtime/`는 변경하지 않았습니다.
