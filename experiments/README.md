# 콘텐츠 제작 파일

실험별 문안·이미지·제작 파일을 이 폴더에 모읍니다. 조사 근거, 목표, 결과 수치와 다음 결정은 기존 Notion 실험 기록에서 관리합니다.

## 저장 방법

- 폴더 이름은 `YYYY-MM-DD-짧은주제`로 만듭니다. 날짜는 폴더를 만든 날이며 게시 완료를 뜻하지 않습니다.
- 문안은 `draft.md`, 이미지·영상은 같은 실험 폴더에 둡니다. 확정 게시본이 초안과 다르면 `published.md`에 실제 사용한 문안을 보존합니다.
- 문안 상단에 관련 Notion 기록 링크와 파일 용도를 적습니다. 게시 여부·URL을 확인할 수 없으면 미확인으로 표시합니다.
- 외부 소재를 저장할 때는 출처·확인일·사용 허락 범위를 함께 남깁니다. 제품 보유와 직접 사용 여부도 실제 확인한 내용으로 표시합니다.
- 새 실험이 정해졌을 때만 폴더를 만듭니다. 양식을 채우기 위해 상품이나 실험을 추가하지 않습니다.

문안 파일의 최소 형식:

```markdown
# 콘텐츠 문안

- 용도: 게시 전 초안
- Notion 기록: 관련 기록 링크
- 상품·소재 출처와 확인일: 확인한 원문 링크와 날짜
- 직접 사용·소재 사용 범위: 확인 내용 또는 미확인

본문
```
